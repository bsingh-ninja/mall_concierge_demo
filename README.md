# Mall Concierge (demo)

A shopper scans a QR code at the entrance and types into the prompt bar, e.g. "I have 2 hours, kids with me, want sneakers under 400 and lunch."
Five agents plan the visit; midway, the planned restaurant gets busy and the shopper is rerouted next door with a
15% coupon. Then the screen flips (press **O**) to the mall-operator view: heatmap, converted offers, underperforming tenants.

```
./start.sh            # API :8004, web :3004 (also on the LAN IP; the desktop page shows a QR for phones)
```

| Agent | Where | What it does |
|---|---|---|
| Concierge chat | `backend/app/concierge.py` | Gemini chats grounded in the mall's stores, offers and queues; empty or vague messages get suggestions + tap-to-send replies; once it knows one goal it hands a structured intent to the planner |
| Intent parser | `backend/app/agents.py` `parse_intent` | Gemini structured output; regex rules fallback if no key / timeout |
| Live crowd | `occupancy`, `wait_minutes` | Simulated footfall per store (lunch curve + noise); the queue spike is scripted |
| Offer matcher | `match_offers` | Budget filter + discount, kids' range, popularity, crowd; picks the restaurant |
| Upsell | `pick_upsell`, `pick_alternative` | Offers from tenants under 85% of sales target, ≤ 3 min detour |
| Route planner | `plan_route`, `app/mall.py` `astar` | A* on the corridor graph, best stop order, trims to the time budget |

- Mall data: `backend/app/data/mall.json`, generated by `backend/scripts/build_mall.py` (60 stores, 64 offers, floor plan + graph). Mall name is the `name` field.
- Sessions live in memory: restarting the API resets the operator view.
- Top bar: Shopper / Operator switch (key **O**) and **Simulate lunch crowd surge** (key **S**), which reroutes the active visit at once.
- Map: architectural floorplan with units U-01..U-60 (play zone P-01); "Show A* graph nodes" draws the backend's corridor graph with edge weights in metres. Walking speed 1.2 m/s.
- Operator console: telemetry strip, footfall heatmap (click a unit to inspect; dashed = below target), offer ledger, tenant alerts with a proximity boost the upsell agent then favours, and the JSON trace of every agent step.
- Photos: `web/public/img`, Creative Commons, credits in `IMAGE_CREDITS.md`.
- The reroute fires while the shopper is at the stop before lunch (8 min in).
